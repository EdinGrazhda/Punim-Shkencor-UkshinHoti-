# HTML Fundamentals

An HTML element uses an opening tag and a closing tag to mark a piece of page content.

The `<!DOCTYPE html>` declaration tells the browser to use the modern HTML standard when it reads a document.

The `<head>` element contains metadata such as the page title, and the `<body>` element contains the content shown on the page.

An `<a>` element creates a link, and its `href` attribute identifies the destination resource.

An `<img>` element displays an image, and its `src` attribute identifies the image file.

The `alt` attribute provides a text alternative that can describe an image to people who cannot see it.

An unordered list uses a `<ul>` element with each list item inside an `<li>` element.

Semantic elements such as `<main>`, `<nav>`, and `<footer>` describe the purpose of different page regions.
